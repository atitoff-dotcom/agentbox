# Журнал ошибок и замечаний AgentBox

В этот файл фиксируются все ошибки, нештатные ситуации и проблемы при работе с `agentbox`, сопровождаемые комментариями и предложениями по исправлению.

| Дата / Время | Команда / Контекст | Наблюдаемая ошибка / Поведение | Анализ причины | Комментарий / Решение |
|---|---|---|---|---|
| 2026-10-12 09:22 | `agentbox run "python -c '... print(\"\"...) '"` | `SyntaxError: unterminated string literal` (`print(" \.join...`) | В PowerShell на Windows вложенные экранированные кавычки `\"\"` внутри аргумента командной строки интерпретируются парсером PowerShell как `" \`, искажая код команды до передачи в CLI. | Для сложных скриптов python не передавать многоуровневые кавычки через CLI-аргумент PowerShell. Использовать одинарные кавычки в Python, либо запускать через файл скрипта (`agentbox write script.py` + `agentbox run "python script.py"`). |
| 2026-10-12 09:23 | `agentbox run 'python -c "import pyferro; print(pyferro.__file__)"'` | `agentbox: error: unrecognized arguments: pyferro; print(pyferro.__file__)` | В `agentbox/cli.py` аргумент команды объявлен как `p_run.add_argument("command")` (ровно 1 позиционный аргумент без вариативного списка аргументов). При вызове из PowerShell одинарные кавычки вокруг команды снимаются шеллом, в результате чего аргументы команды разбиваются на отдельные элементы `sys.argv` (`python`, `-c`, `import...`), и argparse падает с ошибкой unrecognized arguments. | В `agentbox` поддержать вариативный список аргументов (`nargs=argparse.REMAINDER`) для `run`, `test`, `spawn` и склеивать их в единую строку команды (`" ".join(args.command)`), чтобы аргументы и флаги запускаемой утилиты не конфликтовали с парсером CLI. |
