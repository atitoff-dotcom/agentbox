**Инструмент для бережливой, безопасной и быстрой работы ИИ-программистов на вашем компьютере и удалённых серверах.**

Создан специально для современных ИИ-ассистентов: **Claude Code, Cursor, Antigravity, Aider, Roo-Code, Windsurf** и любых других LLM-агентов.

---

## 🧐 Что это такое простыми словами?

Представь, что ты нанял умного помощника (ИИ-агента), чтобы он починил баг в проекте. Но у него есть три неприятные привычки:

1. **Он читает книги целиком ради одной строчки.** Если нужно поправить функцию в файле на 1000 строк, агент считывает весь файл. Ты платишь за тысячи лишних токенов, контекст переполняется, а агент начинает «тупить» и забывать начало разговора.
2. **Он ломает команды кавычками.** Когда агент пытается запустить скрипт или команду в терминале Windows (PowerShell) или по SSH, кавычки путаются, ломаются, и терминал выдаёт ошибку `SyntaxError` или `unexpected EOF`.
3. **Он заваливает чат мусором.** Запустил тесты — в чат прилетело 500 строк логов успешных тестов. Запустил сборку — ещё 300 строк. Полезной информации ноль, а токены улетели в трубу.

**AgentBox решает все эти проблемы:**
* Даёт агенту команду посмотреть только «скелет» файла (`outline`) или конкретную функцию (`get-fn`).
* Запускает тесты «молча»: если всё прошло успешно — выводит короткое `OK`. Если тест упал — показывает **только место ошибки**, без сотен строк мусора.
* Передаёт изменения файлов безопасно (через Base64 или временные файлы), поэтому кавычки в PowerShell и Bash **никогда не ломаются**.
* Умеет прозрачно подключаться к удалённым серверам по SSH: сам на лету ставит туда лёгкого помощника без ручной настройки.

## ⚡ Сколько токенов это экономит?

AgentBox сокращает расход токенов в диалоге с ИИ на **80–95%**:

| Что нужно сделать | Как делает обычный ИИ | С AgentBox | Экономия токенов |
|---|:---:|:---:|:---:|
| **Изучить файл на 800 строк** | Читает файл целиком (`~3 000` токенов) | `agentbox outline` (`~120` токенов) | **-96%** ⚡ |
| **Посмотреть одну функцию** | Читает наугад 100 строк (`~600` токенов) | `agentbox get-fn` (`~150` токенов) | **-75%** 📉 |
| **Собрать проект / билд** | Вываливает 200 строк логов (`~1 500` токенов) | `agentbox run` в тихом режиме (`~40` токенов) | **-97%** ⚡ |
| **Отредактировать функцию** | Пишет `cat` / гигантский diff (`~400` токенов) | `agentbox patch` (`~60` токенов) | **-85%** 📉 |
| **Посмотреть структуру папок** | `find .` или `tree` с мусором (`~1 200` токенов) | `agentbox tree` без мусора (`~150` токенов) | **-88%** 📉 |

## 🚀 Быстрый старт: настройка за 60 секунд

Тебе не нужно учить наизусть 30 команд. Вся настройка состоит из 3 шагов: поставить утилиту, описать проект в одном файле и сгенерировать правила для ИИ. Дальше твой ИИ-ассистент будет использовать AgentBox сам!

### Шаг 1. Установи AgentBox
Нужен только установленный Python 3.8 или новее:
```bash
pip install ai-agentbox
```

### Шаг 2. Создай конфиг `.agentbox.json` в корне своего проекта
Этот файл объясняет, где запускать команды (на твоем компьютере или на серверах) и какие есть частые задачи.

Создай файл `.agentbox.json` рядом с твоим кодом:
```json
{
  "default_target": "local",
  "targets": {
    "local": {
      "cwd": "."
    },
    "dev": {
      "host": "developer@dev.server.com",
      "cwd": "/home/developer/app",
      "venv": "/home/developer/app/.venv"
    },
    "prod": {
      "host": "deploy@prod.server.com",
      "cwd": "/var/www/backend",
      "readonly": true
    }
  },
  "tasks": {
    "test": "pytest tests/ -v",
    "build": "python -m build",
    "db": "psql -U postgres -d mydb -c {args}"
  }
}
```

> [!TIP]
> * **Работа локально без настроек:** Если у тебя нет серверов и ты не хочешь создавать конфиг прямо сейчас — AgentBox сразу готов к работе локально из коробки.
> * **Защита продакшена (`readonly: true`):** Если пометить сервер как `readonly: true`, агент физически **не сможет ничего там сломать**: команды записи (`write`, `patch`, `sync push`) и произвольного запуска (`run`, `spawn`) будут заблокированы. Агент сможет только безопасно читать логи и изучать код.

*(Если не любишь писать JSON руками, можно добавлять серверы и команды через консоль: `agentbox target add dev --host user@server --cwd /path` и `agentbox task add test "pytest"`).*

---

### Шаг 3. Сгенерируй правила для своего ИИ-ассистента

Выполни одну команду в папке проекта:
```bash
agentbox rules
```

Эта команда создаст файл `AGENTS.md` (или `.cursorrules` / `CLAUDE.md`, если указать флаг `--type cursor` или `--type claude`).

В этот файл автоматически запишутся строгие инструкции для ИИ:
* Не читать файлы целиком и не спамить командами вроде `cat`, `grep` или `find`.
* Использовать экономные команды `agentbox`.
* Список всех доступных серверов (с отметками Read-Only) и готовых рецептов задач.

Если ты позже добавил новые серверы или команды в `.agentbox.json`, просто обнови правила:
```bash
agentbox rules --sync
```

---

### Шаг 4. Отдай задачу ИИ-ассистенту!

Открой свой привычный редактор или агент (**Cursor, Claude Code, Antigravity, Windsurf, Roo-Code, Aider**) и просто напиши задачу на человеческом языке:

> *«Проверь сервис авторизации на сервере prod, найди функцию verify_token, а тесты прогони на сервере dev».*

ИИ сам прочитает `AGENTS.md` и сделает всё красиво:
1. Подключится по SSH без лишних вопросов.
2. Быстро запустит на удаленном сервере изолированного воркера.
3. Прочитает только нужную функцию через `agentbox get-fn`.
4. Прогонит тесты тихо через `agentbox task test` и вернет понятный отчет!

## 🧰 Шпаргалка по основным командам

Хотя обычно команды запускает сам ИИ, ты можешь пользоваться ими и вручную:

| Категория | Команды | Что делает простыми словами |
|---|---|---|
| **Серверы и задачи** | `agentbox target`<br>`agentbox task` | Переключает серверы (`local`, `dev`, `prod`) и запускает сохранённые рецепты команд. |
| **Изучение кода** | `agentbox outline`<br>`agentbox get-fn`<br>`agentbox find-fn`<br>`agentbox view`<br>`agentbox tree`<br>`agentbox grep` | Показывает список функций в файле, достаёт одну функцию целиком, ищет по проекту без лишнего мусора в выводе. |
| **Безопасные правки** | `agentbox patch-lines`<br>`agentbox write`<br>`agentbox cp`<br>`agentbox patch`<br>`agentbox rollback` | Меняет строки в файле без поломки кавычек в терминале, делает автобэкап и умеет откатывать изменения (`rollback`). |
| **Тихий запуск** | `agentbox test`<br>`agentbox run`<br>`agentbox spawn`<br>`agentbox logs`<br>`agentbox kill` | Запускает тесты и билды без информационного шума; фоновые процессы живут даже при закрытии SSH-сессии. |
| **Экономный Git** | `agentbox git-status`<br>`agentbox diff`<br>`agentbox git-log`<br>`agentbox git-view` | Компактный статус git, diff без пробельного мусора и огромных lock-файлов, история коммитов в 1 строку. |
| **Синхронизация и граф** | `agentbox sync`<br>`agentbox graphify-*`<br>`agentbox daemon` | Синхронизирует папки между сервером и компом, строит карту архитектуры кода, держит быстрый канал связи (2–5 мс). |

👉 **Полное описание каждой команды со всеми параметрами и примерами смотри в [Подробном руководстве по CLI (`docs/CLI.ru.md`)](docs/CLI.ru.md).**

## 💡 Почему это работает так надежно?

* **Чистый Python без сторонних зависимостей:** AgentBox использует только стандартную библиотеку Python (`argparse`, `ast`, `subprocess`, `json`, `socket`). Не нужно компилировать C-библиотеки или ставить тяжелые пакеты.
* **Саморазворачивающийся воркер (Zero-Setup):** При первом подключении к удаленному серверу AgentBox сам за доли секунды копирует туда легковесный скрипт `worker.py`. Тебе не нужно ничего вручную ставить на сервер.
* **Сверхбыстрый демон-мост (2–5 мс):** Чтобы не тратить по 1-2 секунды на SSH-рукопожатие при каждой команде, AgentBox держит быстрое соединение в памяти. Команды выполняются мгновенно.
* **Протокол Zero-Escaping:** Забудь о сломанных кавычках на Windows! Код и команды передаются через Base64, временные файлы или стандартный ввод, поэтому любые спецсимволы доходят до исполнителя в первозданном виде.
* **Изолированное окружение (`.agentbox/venv`):** AgentBox создает и использует изолированный виртуальный venv, гарантируя, что системный Python на сервере не будет случайно сломан.

## ❓ Частые вопросы (FAQ)

<details>
<summary><b>Нужно ли мне что-то устанавливать на удалённый сервер?</b></summary>
Нет! На удалённом сервере достаточно иметь обычный Python (3.8+). Когда ты впервые выполнишь команду с флагом <code>-t dev</code>, AgentBox сам за доли секунды скопирует и запустит туда своего рабочего воркера.
</details>

<details>
<summary><b>Что делать, если ИИ написал плохой код и сломал файл?</b></summary>
Просто запусти <code>agentbox rollback <путь_к_файлу></code>. AgentBox делает резервную копию перед каждым изменением файла.
</details>

<details>
<summary><b>Как AgentBox понимает, какую часть файла читать?</b></summary>
AgentBox использует встроенный парсер синтаксического дерева кода (AST). Он видит границы классов и функций так же, как сам компилятор языка, поэтому вырезает ровно нужный фрагмент без гаданий по номерам строк.
</details>

<details>
<summary><b>Работает ли это на Windows?</b></summary>
Да, на 100%! AgentBox специально разрабатывался с учетом особенностей Windows PowerShell и cmd.exe, защищая от проблем с кодировкой UTF-8 и ломающихся кавычек.
</details>
